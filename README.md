# Universal ETC — Website

# Platform Promosi dan Layanan Informasi Otomatis Bimbingan Belajar Berbasis Web dan Chatbot.

# Deskripsi Masalah

1. Calon siswa atau orang tua sering kesulitan mendapatkan informasi cepat mengenai program les, harga, dan jadwal di luar jam operasional (malam hari atau hari libur).

2. Admin bimbingan belajar kewalahan karena harus menjawab pertanyaan berulang (FAQ) yang sama setiap harinya (seperti lokasi, rincian biaya, dan syarat pendaftaran).

3. Kurangnya sistem pendataan (lead capture) otomatis, sehingga banyak pengunjung website yang tertarik berlalu begitu saja karena admin terlambat merespons.

# Profil Target Pengguna

1. Calon Siswa (SMP/SMA) & Orang Tua Siswa: Pengguna yang mengakses website untuk mencari tahu kualitas, harga, dan program bimbingan belajar.

2. Admin Tempat Les: Pengguna yang login ke sistem untuk melihat data kontak pengunjung yang tertarik mendaftar.

# Manfaat Aplikasi

1. Memberikan pelayanan informasi 24/7 kepada calon siswa dan orang tua tanpa jeda waktu tunggu.

2. Meringankan beban kerja admin sehingga bisa lebih fokus pada proses pendaftaran dan follow-up calon siswa.

3. Meningkatkan profesionalitas dan kredibilitas bimbingan belajar di mata masyarakat.

4. Mengumpulkan data prospek (leads) secara otomatis melalui chatbot untuk keperluan marketing.

# Daftar Fitur Inti (Realistis untuk 12 Pertemuan)

1. Halaman Landing Page (Promosi): Menampilkan profil bimbingan belajar, daftar program, keunggulan, testimoni, dan galeri foto.

2. Widget Chatbot Interaktif: Chatbot pintar di pojok website yang mampu merespons pertanyaan seputar info les (harga, jadwal, lokasi) secara otomatis.

3. Fitur Pengumpulan Prospek (Lead Capture): Chatbot mampu meminta dan menyimpan nama serta nomor WA/email pengunjung yang berniat mendaftar atau butuh konsultasi lanjutan.

4. Dashboard Admin Sederhana: Halaman khusus admin (dengan sistem login) untuk mengelola FAQ chatbot dan melihat tabel data calon siswa yang berhasil dikumpulkan oleh bot.

# Fitur yang Tidak Dikerjakan (Out of Scope)

1. Sistem Pembayaran Online (Payment Gateway).

2. Learning Management System (LMS) seperti fitur kuis, pengumpulan tugas, atau video streaming materi belajar.

3. Fitur Live Chat atau Handover ke agen manusia (sistem hanya fokus menggunakan bot otomatis).

3. Sistem absensi siswa dan penggajian tutor/pengajar.

# Kriteria Aplikasi Dinyatakan Berhasil

1. Website landing page berhasil di-deploy secara online dan responsif (tampilan rapi saat dibuka di HP maupun PC).

2. Chatbot mampu memberikan jawaban yang relevan dan akurat berdasarkan knowledge base atau FAQ yang sudah ditentukan.

3. Data kontak (nama dan nomor telepon/email) yang dimasukkan pengguna lewat chatbot berhasil masuk dan tersimpan ke dalam database.

4. Admin dapat login ke dashboard dan melihat data kontak pengunjung tersebut dengan baik.
